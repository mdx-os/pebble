# What `make mutation-check` breaks, and the tests that must then fail.
# Format: see scripts/mutation-check.sh. Substitutions use ~ as the
# delimiter. An entry that needs several changes gives each its own perl:
# line, and each must apply.
#
# The source guards. Each rule in GuardScan (Tools/GuardKit) is turned off
# on its own, and the wrong-case suite for its guard must fail: no rule can
# stop catching its cases unseen. Then the scanner's own reading is broken,
# one way at a time, and the cases that rest on it must fail.
