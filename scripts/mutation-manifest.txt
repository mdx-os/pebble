# What `make mutation-check` breaks, and the tests that must then fail.
# Every new behavior test gets an entry here (see AGENTS.md). Format: see
# scripts/mutation-check.sh. Substitutions use ~ as the delimiter, or #
# where the code itself holds a ~. An entry that needs several changes
# gives each its own perl: line, and each must apply.
#
# The check runs `swift test` only, so the UI tests in AppUITests can't be
# named here. Each promise a UI test checks in the app has a package twin
# that pins the same thing and has entries below:
#   testThePreviewShowsTheRequestAndReadsWell: whatThePreviewCoversIsPinnedOnTheCardAndAloud,
#     voiceOverNeverReadsASignInValue, voiceOverHearsTheSignInHopsBody,
#     theSheetSaysValuesAreCoveredWheneverOneIs
#   testThePreviewTextCantBeCopied: thePayloadCantBeSelectedOrCopied
#   testThePrivateWordsSayWhatTheyCanMiss: anotherSpellingCanStillSlipBy
#   testTurningOnAsksFirst: theQuestionPromisesSignInCarriesNothingPrivate
# A new UI test that guards a promise gets a twin here before it lands.
